qb-assistant privacy policy

Last updated: October 17, 2026

qb-assistant is a private assistant operated by QBTechnologies for the members of one household. This page explains what it does with the Google account data it is allowed to access.

Who uses it

Only the members of that household, signing in with their own Google accounts. qb-assistant is not offered to the public.

What it accesses

With the owner's permission, qb-assistant reads messages in the owner's Gmail inbox and sent mail, and adds or removes a small set of its own labels (QB_vetted, QB_new, QB_muted, QB_allow, QB_reject) so the owner can see and correct how each message was sorted. It does not read the Spam or Trash folders.

What it does with the data

  • Messages from senders the owner already knows are summarized into a private notes folder on a computer the owner controls, so the owner can search them later.
  • The sender list it uses is built from addresses the owner has emailed and from the owner's own contacts.
  • It never sends, forwards, drafts or deletes email.
  • It does not sell, share or transfer Gmail data to anyone, and does not use it for advertising.
  • To write those notes, message content is sent to Anthropic's Claude service, for that purpose only. QBTechnologies does not use Gmail data to develop or train AI models.

Where data is kept

Notes and settings are stored on the household's own computer. Sign-in tokens are kept in that computer's system keychain. No Gmail data is stored on QBTechnologies servers.

Removing access

The account owner can revoke qb-assistant's access at any time at myaccount.google.com/permissions. Notes already filed can be deleted from the household computer at the owner's request.

Google API Services

qb-assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: use the support email shown on qb-assistant's Google sign-in screen.
